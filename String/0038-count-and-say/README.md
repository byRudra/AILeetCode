# 38. Count and Say

![Medium](https://img.shields.io/badge/Difficulty-Medium-ffc01e?style=flat-square) [Open on LeetCode](https://leetcode.com/problems/count-and-say/)

`String`

## Intuition  
The whole sequence can be generated by repeatedly applying a **run‑length encoding** to the previous string: while scanning the current term, every maximal block of equal characters contributes exactly two new characters – the block length followed by the digit itself. A naïve solution would recompute earlier terms from scratch for each `n` (or store all of them), which costs extra passes or memory. The insight is that a single left‑to‑right pass over the current term is sufficient to produce the next term, so we can iterate `n‑1` times and keep only the latest string.

## Approach  
1. **Initialize** `result = "1"` – this is the base case `countAndSay(1)`.  
2. **Outer loop** `for (int i = 2; i <= n; i++)` builds the `i`‑th term.  
   - *Invariant*: before each iteration `result` holds `countAndSay(i‑1)`.  
3. Inside the outer loop, create an empty `StringBuilder next` and set `count = 1`.  
4. **Inner loop** `for (int j = 1; j < result.length(); j++)` scans `result` from the second character.  
   - *Invariant*: `count` equals the size of the current run that ends at position `j‑1`.  
   - If `result.charAt(j) == result.charAt(j‑1)`, the run continues → `count++`.  
   - Otherwise the run ends: append `count` and the character `result.charAt(j‑1)` to `next`, then reset `count = 1` for the new run starting at `j`.  
   - The `else` branch uses `<=`‑style logic implicitly because the loop stops before the last character; the final run is handled after the loop.  
5. After the inner loop finishes, the last run (which never triggers the `else`) is emitted by  
   `next.append(count); next.append(result.charAt(result.length() - 1));`.  
6. Convert `next` to a string and assign it back to `result`. This satisfies the outer‑loop invariant for the next iteration.  
7. When the outer loop ends, `result` holds `countAndSay(n)` and is returned.

Edge cases:  
- `n == 1` skips the outer loop, returning the initialized `"1"`.  
- Single‑character strings are handled because the inner loop body never executes and the final append writes `"11"`.  

## Dry Run  
**Input:** `n = 4`  

| i (outer) | j (inner) | count | next (built so far) | changed element |
|-----------|-----------|-------|---------------------|-----------------|
| 2 | – | 1 | "" | start with result = "1" |
| 2 | (no j, length=1) | 1 | "" → after loop `next.append(1)` & `next.append('1')` → "11" | result becomes "11" |
| 3 | j=1 | count=1 (chars equal) → count=2 | "" | still inside run of '1' |
| 3 | (loop ends) | 2 | "" → after loop `next.append(2)` & `next.append('1')` → "21" | result becomes "21" |
| 4 | j=1 | result.charAt(1)='1' ≠ result.charAt(0)='2' → append `1` `2` → next="12", reset count=1 |
| 4 | j=2 | chars equal ('1'=='1') → count=2 |
| 4 | (loop ends) | 2 | next currently "12" → append `2` `1` → "1211" | result becomes "1211" |

After the third outer iteration (`i = 4`) the algorithm stops; `result = "1211"` which is exactly the 4‑th term.

## Complexity  
- **Time:** `O(L)` where `L` is the total number of characters processed across all iterations. Each inner loop visits every character of the current term exactly once, and the outer loop runs `n‑1` times, so the work is proportional to the length of the final string.  
- **Space:** `O(K)` extra, where `K` is the length of the term being generated (`next`). Only two strings (`result` and `next`) are kept simultaneously; the output itself is not counted against the auxiliary space.

## Solution (Java)

```java
class Solution {
    public String countAndSay(int n) {
        String result = "1";
        for(int i = 2; i <= n; i++){
            StringBuilder next = new StringBuilder();
            int count = 1;

            for(int j = 1; j < result.length(); j++){
                if(result.charAt(j) == result.charAt(j - 1)){
                    count++;
                }
                else{
                    next.append(count);
                    next.append(result.charAt(j-1));
                    count = 1;
                }
            }
            next.append(count);
            next.append(result.charAt(result.length() - 1));
            result = next.toString();

        }
        return result;
    }
}
```
